### Step 1C: Migrate Inter Tight to `next/font`
- [x] **DONE** — Added `Inter_Tight` via next/font, removed Google Fonts link tags, updated CSS to use `var(--font-inter-tight)` fallback

Inter Tight loads via external Google Fonts `<link>` tag, creating:

- 2 extra font file downloads from `fonts.gstatic.com` (~46KB)
- The 0.001 CLS on `<h1>` from font-swap flash

**File 1:** `app/layout.tsx`

Changes:
1. Add import: `import { Inter_Tight } from "next/font/google";` (alongside existing `Inter` import on line 2)
2. Add font config after the existing `inter` config (after line 12):
```tsx
const interTight = Inter_Tight({
  subsets: ["latin"],
  display: "swap",
  variable: "--font-inter-tight",
  weight: ["500", "600", "700", "800", "900"],
});
```
3. Update `<html>` tag (line 70) to include both variables:
```tsx
<html lang="en" className={`${inter.variable} ${interTight.variable}`}>
```
4. Remove these 3 lines from `<head>` (lines 72-81):
```tsx
// DELETE these:
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossOrigin="anonymous" />
<link href="https://fonts.googleapis.com/css2?family=Inter+Tight:wght@500;600;700;800;900&display=swap" rel="stylesheet" />
```

**File 2:** `app/globals.css`

Update the `@theme inline` block (line 63) and `.font-display` class (line 79-80) to use the CSS variable generated by `next/font`:
- Line 63: Change `--font-display` to: `'Inter Tight', -apple-system, BlinkMacSystemFont, sans-serif;` (keep as-is — the `next/font` variable `--font-inter-tight` maps at the `<html>` level, and the font-family name `'Inter Tight'` still works because `next/font` auto-registers the font face with that name)

Actually — the simpler approach: `next/font` with `variable: "--font-inter-tight"` creates a CSS variable `--font-inter-tight` on the html element containing the font family value. Update globals.css to use it:
- In `@theme inline`, change line 63 to: `--font-display: var(--font-inter-tight, 'Inter Tight'), -apple-system, BlinkMacSystemFont, sans-serif;`
- In `.font-display` class (line 79-80), change to: `font-family: var(--font-inter-tight, 'Inter Tight'), -apple-system, BlinkMacSystemFont, sans-serif;`

## Phase 6: Optional / Lower Priority

### Step 6A: Security Headers (CSP, COOP)
- [x] **DONE** — Added X-Frame-Options, X-Content-Type-Options, Referrer-Policy, COOP, and CSP-Report-Only to next.config.ts headers()

Not affecting performance score but flagged under Best Practices. Add security headers via Next.js config.

**File:** `next.config.ts`

Add a `headers()` function:
```ts
const nextConfig: NextConfig = {
  images: { ... },
  async headers() {
    return [
      {
        source: '/(.*)',
        headers: [
          { key: 'X-Frame-Options', value: 'DENY' },
          { key: 'X-Content-Type-Options', value: 'nosniff' },
          { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
          { key: 'Cross-Origin-Opener-Policy', value: 'same-origin' },
          {
            key: 'Content-Security-Policy-Report-Only',
            value: [
              "default-src 'self'",
              "script-src 'self' 'unsafe-inline' 'unsafe-eval' https://static.cloudflareinsights.com https://us-assets.i.posthog.com",
              "style-src 'self' 'unsafe-inline'",
              "font-src 'self'",
              "img-src 'self' data: blob:",
              "connect-src 'self' https://us.i.posthog.com https://us-assets.i.posthog.com",
            ].join('; '),
          },
        ],
      },
    ];
  },
};
```

**Important:** Start with `Content-Security-Policy-Report-Only` (not `Content-Security-Policy`) to test without breaking anything. Monitor the browser console for CSP violations. Once clean, switch to enforcing mode.

**Verify:** `npm run build`, check response headers in browser DevTools Network tab.
